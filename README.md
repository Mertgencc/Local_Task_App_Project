### To-Do App Project

A simple and interactive To-Do application built with HTML, CSS, and JavaScript.  
This project allows users to add and delete tasks dynamically using DOM manipulation.

<img width="1366" height="644" alt="image" src="https://github.com/user-attachments/assets/a2f234be-a92e-47a7-ba36-37d8f399741a" />

---

#### 🚀 Features
- Add new tasks
- Delete existing tasks
- Dynamic list rendering
- Simple and clean UI

---

#### 🛠 Technologies Used
- HTML
- CSS
- JavaScript (Vanilla JS)

---

#### 📌 Purpose
This project was built to practice JavaScript fundamentals such as DOM manipulation, event handling, and basic application logic.

---

#### 📷 Preview
A minimal To-Do application interface where users can manage their daily tasks.

---

#### 💡 Future Improvements
- LocalStorage integration (save tasks permanently)
- Mark tasks as completed
- Improved UI/UX design

---

#### 📁 How to Run
Simply open `index.html` in any modern browser.
